# Group photos

The `.svg` files here are placeholders so the gallery on `people.html` renders
before real photos exist. To use a real photo, drop it in this folder and point
the matching `<img src>` in `people.html` at it, e.g.

    assets/img/group/group-photo.svg  ->  assets/img/group/group-photo.jpg

Suggested sizes: 1600x600 for the wide banner shot, 1200x900 (4:3) for the rest.
Keep files under ~300 KB each; export at 72–96 dpi. Always update the `alt`
text to describe what is actually in the photo.
