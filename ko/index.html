01  /  학과

하나의 연구실, 두 학과

가속기 기반 이기종 시스템은 대규모 응용을 실행하는 사실상의 표준이 되었지만, 모델 설계자와 기계 사이에는 여전히 프로그래밍 장벽이 놓여 있습니다. 우리는 그 장벽의 양쪽을 모두 연구합니다.

컴퓨터공학부

딥러닝과 양자 컴퓨팅을 위한 실행 플랫폼

GPU와 FPGA, 클러스터를 위한 컴파일러와 런타임 시스템, 프로그래밍 환경. 모델 설계자가 기계를 속속들이 알지 못해도 기계를 온전히 쓸 수 있도록 만듭니다.

  • 01자동 병렬화 — 다중 노드·다중 GPU 시스템에서 DNN에 가장 적합한 병렬화 기법을 자동으로 찾습니다.
  • 02GPU 메모리 너머 — DeepUM과 SnuRHAC은 CUDA Unified Memory와 호스트 메모리, SSD를 활용해 GPU 용량을 넘어선 실행을 가능하게 합니다.
  • 03FPGA를 위한 프레임워크 — SOFF는 사용자 주석 없이 OpenCL과 CUDA를 FPGA로 합성합니다.
  • 04양자 시뮬레이션 — SnuQS는 저장장치를 이용해 전체 상태 회로 시뮬레이션을 확장합니다.
데이터사이언스대학원

한국어를 위한 대규모 언어 모델

리더보드가 염두에 두지 않았던 언어를 위한 데이터셋과 토크나이저, 모델. 그리고 그것이 실제로 작동했는지 말할 수 있게 해 주는 평가.

  • 01한국어 데이터셋 — LLM 학습을 위한 대규모 웹 크롤링과 비식별화, 중복 제거.
  • 02한국어 토크나이저 — 형태소를 고려해 단어당 토큰 수를 줄이는 Thunder-Tok.
  • 03한국어 언어 모델 — 최소한의 자원으로 한국어에 적응시킨 Thunder-LLM.
  • 04벤치마크 — 모델이 아직 하지 못하는 것을 재는 Thunder-NUBench와 Thunder-KoNUBench.
02  /  현재 연구

네 가지 연구 분야

각 분야마다 학생과 코드, 발표된 결과가 뒤에 있습니다. 연구 페이지에 자세히 적어 두었습니다.

01

딥러닝을 위한 실행 플랫폼

다중 노드·다중 GPU 시스템에서의 DNN 자동 병렬화, 메모리와 클러스터를 투명하게 다루는 DeepUM과 SnuRHAC, 커널을 생성하는 DeepCuts, 그리고 FPGA를 위한 풀스택 딥러닝 프레임워크.

병렬화통합 메모리FPGA커널
02

대규모 언어 모델

처음부터 만든 한국어 데이터셋과 토크나이저, 언어 모델. 그리고 그것을 감당할 수 있게 만드는 학습 기법과 에너지 특성 분석, 모델 압축.

한국어 데이터토크나이저모델 압축에너지
03

양자 컴퓨팅

컴파일러와 런타임, 시뮬레이터로 이어지는 소프트웨어 스택. SnuQS는 NVMe SSD와 HDD를 갖춘 워크스테이션에서 42큐비트 양자 우위 회로를 시뮬레이션했으며, 이는 기존 전체 상태 시뮬레이터보다 256배 큰 규모입니다.

SnuQS전체 상태 시뮬레이션저장장치 I/O
04

언더디스플레이 카메라 영상 복원

디스플레이 아래에 놓인 카메라는 빛을 잃고 회절을 얻습니다. 우리는 합성 열화가 아니라 실제 환경을 담은 데이터셋 UDC-SIT과 UDC-VIT을 만들고, 그 위에서 동작하는 딥러닝 복원 기법을 연구합니다.
