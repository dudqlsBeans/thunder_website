01  /  연구 조직

컴퓨터공학부와 서울대 AI대학원을 잇는 연구

대규모 AI의 성능과 효율을 높이려면 모델의 특성과 하드웨어의 구조를 함께 고려해야 합니다. 천둥 연구실은 컴퓨터공학과 AI의 전문성을 바탕으로 AI 모델과 이를 실행하는 시스템을 함께 연구합니다.

컴퓨터공학부

딥러닝과 양자 컴퓨팅을 위한 실행 플랫폼

GPU·FPGA와 클러스터 환경을 위한 컴파일러, 런타임, 프로그래밍 기술을 연구합니다. 복잡한 하드웨어 구조를 직접 다루는 부담을 줄이고, 가속기의 성능을 효과적으로 활용할 수 있도록 합니다.

  • 01이기종 가속기 — NVIDIA, AMD GPU 혼합 환경의 통신, CUDA Unified Memory, NPU, FPGA에서의 AI 연산 최적화
  • 02커널 수준 최적화 — Tensor Core 기반 FFT와 Convolution, NPU 기반 GEMM, FPGA-GPU 하이브리드 연산
  • 03분산 추론 — MoE 추론 효율화, GPU 클러스터의 에너지 사용량 분석, 사용 패턴 기반 자원 스케줄링
  • 04양자-고전 하이브리드 — 고전 컴퓨팅 자원과 스토리지 오프로딩을 활용한 대규모 양자 회로 시뮬레이션
서울대 AI대학원

한국어를 위한 대규모 언어 모델

한국어의 특성을 반영한 데이터셋, 토크나이저, 언어 모델을 개발합니다. 모델의 성능과 한계를 체계적으로 분석하기 위한 평가 방법도 연구합니다.

  • 01효율적인 생성 — 병렬 토큰 생성, 확산 언어모델, 토큰 수를 줄이는 토크나이저
  • 02장문맥·멀티모달 — 위치 인코딩과 어텐션 싱크 분석, 의료영상, 심전도, EMR로의 확장
  • 03평가 — 한국어 벤치마크, 언어 모델과 VLM의 부정 표현 이해
  • 04도메인 특화 모델 — 법률 LLM, 비식별화, 법령 RAG, 임상 바이오마커
