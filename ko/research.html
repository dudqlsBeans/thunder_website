연구 목적

이기종 시스템은 범용 CPU와 GPU·FPGA 등의 가속기를 함께 활용합니다. 딥러닝과 양자 회로 시뮬레이션처럼 대규모 연산이 필요한 분야에서는 하드웨어 자원의 효율적인 활용이 중요합니다. 천둥 연구실은 복잡한 하드웨어 환경에서 프로그래밍 부담을 줄이고 성능을 높이는 기술을 연구합니다.

연구 목표

대규모 응용 프로그램의 성능과 효율 향상

다양한 프로세서를 효율적으로 활용하려면 응용 프로그램의 병렬화와 하드웨어별 최적화가 필요합니다. 이러한 과정을 단순화하고 성능을 높이기 위해 딥러닝 모델, 컴파일러, 런타임, 컴퓨터 구조, 운영체제를 종합적으로 연구합니다.

  • ↓딥러닝을 위한 실행 플랫폼
  • ↓대규모 언어 모델
  • ↓양자 컴퓨팅
  • ↓도메인 특화 언어 모델
핵심 연구 주제

병렬화와 프로그래밍 기술

각 주제의 자세한 설명과 관련 논문, 공개 코드를 아래에서 확인할 수 있습니다.

  • 01딥러닝 프레임워크의 병렬화와 최적화
  • 02대규모 언어 모델의 병렬화와 최적화
  • 03GPU·FPGA 등 이기종 시스템을 위한 프로그래밍 기술
  • 04양자 컴퓨팅을 위한 프로그래밍·시뮬레이션 환경
연구 분야

딥러닝을 위한 실행 플랫폼

심층 신경망의 연산량과 메모리 요구량이 증가하면서 다중 GPU·다중 노드 환경에서의 학습과 추론이 중요해지고 있습니다. 효율적인 병렬화에는 하드웨어와 시스템에 대한 전문 지식이 필요합니다. 천둥 연구실은 병렬화와 최적화를 자동화해 개발자의 부담을 줄이는 실행 플랫폼을 개발합니다.

01

이기종 가속기 및 시스템 최적화

다양한 가속기의 통합 활용과 연산 최적화

TCCL · ASPLOS 2024DeepUM · ASPLOS 2023SOFF · ISCA 2020
  • NVIDIA·AMD GPU 혼합 환경에서의 효율적인 통신 기술 연구(HetCCL)
  • CUDA Unified Memory 기반 CPU·GPU 메모리 활용
  • NPU·FPGA 등 다양한 가속기에서의 AI 연산 최적화
  • Tensor Core 기반 FFT, Convolution 최적화
  • NPU 기반 GEMM 최적화
  • FPGA-GPU 하이브리드 연산
02

분산 추론 및 클러스터 운영 최적화

연산·통신 부하와 자원 사용량을 고려한 추론 최적화

SPipe · PACT 2025
  • 전문가 혼합(MoE) 모델의 연산·통신 부하 불균형 완화
  • GPU 클러스터의 에너지 사용량 측정 및 분석
  • 사용 패턴 기반 자원 스케줄링 최적화
연구 분야

대규모 언어 모델

모델 자체에 대한 연구입니다. 얼마나 빠르게 생성하는지, 얼마나 긴 문맥을 다루는지, 토크나이저를 어떻게 설계하는지, 그리고 벤치마크 점수가 정말 주장하는 바를 재고 있는지.

01

고성능 차세대 언어모델 및 멀티모달 인공지능

한 번에 여러 토큰을 생성하기

  • 대규모 언어모델의 추론 효율 향상을 위한 병렬 토큰 생성 기술 개발Jacobi Decoding, Speculative Decoding 기반 병렬 생성 및 추론 가속화.
  • 확산 언어모델(DLM) 기반 고효율 텍스트 생성 기술 연구자기회귀 언어모델의 확산 모델 전환 및 Masking·Remasking 기반 병렬 디코딩 최적화.
  • 여러 모달리티의 데이터 통합을 위한 멀티모달 언어모델 개발의료영상·심전도·전자의무기록(EMR) 등 다양한 모달리티의 융합 학습 및 예측 성능 개선.
02

Long-Context LLM 최적화 및 멀티모달 모델 학습

긴 문맥을 끝까지 놓치지 않기

TRONTOR · EMNLP 2026
  • 위치 인코딩 조절과 어텐션 싱크 분석을 통한 장문맥 언어모델 성능 향상
  • 장문맥 모델링 기법의 멀티모달 확장 연구
  • 의료 도메인에 특화된 멀티모달 모델 개발
03

토크나이저 개발 및 모델 추론 효율화

같은 문장을 더 적은 토큰으로

Thunder-Tok · arXiv 2025
  • 단어 경계를 넘는 토큰이 언어 모델의 성능과 추론 효율에 미치는 영향 분석
  • multi-word token을 포함하는 토크나이저 개발을 통한 토큰 수 감소 및 모델 추론 가속
  • 텍스트·음성 등 다양한 모달리티의 특성을 반영한 토크나이저 개발
04

언어모델 학습 및 추론 효율화

사전학습 이후에 더 끌어내기

Thunder-LLM · arXiv 2025
  • Post-training을 통한 언어모델 성능 개선
  • 고품질 학습 데이터셋 구축 및 데이터 구성 최적화
  • 언어모델의 생성 구조 개선을 통한 추론 속도 및 효율 최적화
  • 도메인 특화 언어모델 응용
05

언어 모델 평가 및 벤치마크 개발

내년에도 의미가 남는 숫자

Thunder-NUBench · EACL 2026
  • 한국어 이해와 추론 능력을 평가하기 위한 벤치마크 개발
  • 언어 모델이 부정 표현을 이해하는 방식 분석과 성능 개선
  • 선택지나 질문 형식에 따라 평가 결과가 달라지는 문제 분석과 평가 방법 개선

  • 부정 표현 이해 성능이 개선된 시각-언어 인코더 모델 개발
  • 부정 표현 이해 성능이 개선된 생성형 VLM 모델 개발
연구 분야

양자 컴퓨팅

양자 컴퓨터를 효율적으로 활용하기 위한 컴파일러와 런타임을 개발합니다. 양자 하드웨어의 제약을 보완하기 위해 SSD와 HDD를 활용하는 대규모 양자 회로 시뮬레이터도 연구합니다.

01

고성능 양자-고전 하이브리드 컴퓨팅

고전 컴퓨팅 자원을 활용한 대규모 양자 회로 시뮬레이션

SnuQS · ICS 2022
  • 대규모 양자 회로를 고전 컴퓨팅 자원으로 정확히 시뮬레이션하는 플랫폼 개발
  • 스토리지 오프로딩연산에 필요한 데이터만 GPU에 적재해 DRAM 용량의 제약을 완화합니다.
  • 컴파일러·런타임 연계회로 구조를 분석하여 큐비트 배치와 데이터 이동 일정을 컴파일 시점에 결정합니다.
연구 분야

도메인 특화 언어 모델

틀렸을 때의 대가가 큰 영역 — 법률, 개인정보, 전문 문서 검색, 임상 예측 — 에 같은 모델을 겨냥합니다.

01

법률 LLM 개발 및 활용

사건이 실제로 걸려 있는 쟁점 읽어내기

  • 사건의 사실관계에서 주요 법적 쟁점을 찾아내는 모델 연구
  • 한국어 판결문을 활용한 법률 LLM 학습·평가 데이터 구축
  • 관련 법령과 판례를 활용해 쟁점별 판단을 돕는 방법 연구
02

개인정보 비식별화 및 민감 문서 처리

애초에 읽히지 말았어야 할 것을 지우기

Thunder-DeID+ · EMNLP 2026Thunder-DeID · EMNLP 2025
  • 한국어 판결문과 민감 문서의 개인정보 자동 탐지·비식별화 프레임워크 개발(Thunder-DeID, Thunder-DeID+)
  • 개인정보 분류체계 정립 및 개인정보 경계를 고려한 토큰화 기술 개발
  • 토크나이저에 독립적인 비식별화 평가 방법 개발
  • 소량의 추가 학습 데이터를 활용한 다양한 문서 도메인으로의 확장
03

검색 증강 생성(RAG) 및 도메인 특화 정보 검색

결론을 가르는 한 문단을 찾아내기

  • 법령·판례 등 전문 문서의 특성을 반영한 임베딩 모델 및 검색 기술 연구
  • 질의에 적합한 근거 검색·재순위화를 통한 검색 성능 개선
  • 검색된 근거를 활용한 답변 생성 및 도메인 특화 RAG 평가 방법 연구
04

바이오마커 분석 파이프라인

임상 모델이 무엇을 보고 있는지 묻기

  • 의료 영상·생체신호와 임상 정보로 학습된 예측 모델의 주요 요인 발굴
  • 노쇠 예측 적용 및 범용 바이오마커 분석 프레임워크로 확장
  • 멀티모달 언어모델 환경에서의 적용성 및 확장성 검증

연구 방식

연구 원칙

실측에 기반한 성능 검증

실제 하드웨어에서 응용 프로그램의 전체 실행 성능을 측정해 연구 결과를 검증합니다. 세부 연산을 측정하는 마이크로벤치마크를 활용해 성능 변화의 원인을 분석합니다.

연구 결과 공개와 재현성

공개 가능한 범위에서 논문과 함께 코드, 실험 설정, 실행 기록을 제공해 다른 연구자가 결과를 재현할 수 있도록 합니다.

분야 간 공동 검토

시스템 연구자와 AI 모델 연구자가 연구 내용과 결과를 함께 검토합니다. 서로 다른 분야의 전문성을 바탕으로 분석을 보완하고 연구의 완성도를 높입니다.

연구 참여와 협력 제안을 환영합니다.

각 연구 분야에 참여할 학생과 방문연구자를 기다립니다. 관심 있는 연구 주제나 공동 연구 제안은 이메일로 문의해 주시기 바랍니다.
